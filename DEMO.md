1. Show the dashboard and edit a sample answer. Refresh to demonstrate persistence.
2. Add Example Software, role Product Intern, and an Interview round.
3. Paste this fictional JD into the job-description field:

4. For the PDF workflow, save the same fictional text as a text-based PDF and upload it. Analyse locally, review source quotations and approve selected facts. Do not imply this local step uses Gemini.
5. Run local preparation generation. Show editable tasks, completion and linked answers.
6. If a configured Gemini model is available and consent is enabled, preview the payload and explicitly run Gemini. Show the source indicator and review its actual output. If it falls back, explain the failure honestly.
7. Record a review, generate follow-up preparation and show that completed tasks remain intact.
